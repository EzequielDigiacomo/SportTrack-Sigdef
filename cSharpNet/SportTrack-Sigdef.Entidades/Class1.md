# Class1.cs

> Fuente: `SportTrack-Sigdef.Entidades/Class1.cs`

## Qué es este archivo

Placeholder vacío que Visual Studio (o `dotnet new classlib`) genera al crear la class library. **No forma parte del dominio** de SportTrack; se puede borrar sin afectar la app.

```csharp
namespace SportTrack_Sigdef.Entidades
{
    public class Class1
    {
    }
}
```

## Conceptos C# que aparecen

- **`namespace`**: agrupa tipos bajo un nombre común.
- **`public class`**: tipo referencia visible desde otros proyectos.
- **Clase vacía**: válida en C#, pero sin propiedades ni métodos no aporta comportamiento.

## Notas de estudio

- Al crear un proyecto *class library*, el template mete `Class1.cs` por defecto.
- En código real se reemplaza por entidades con nombre de negocio (`Evento`, `Club`, etc.).
- Si ves `Class1` en otros proyectos del solution, suele ser el mismo residuo del template.
